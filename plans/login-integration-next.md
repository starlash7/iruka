- [ ] 작품/시작 상황 로그인 복귀, 모바일/키보드/포털 레이어 QA
- [ ] 실제 Privy Google·이메일 설정과 허용 origin 확인, 실제 로그인 검증

- [ ] 모델·안전 정책·사용 한도·예약/실차감 기준 확정
