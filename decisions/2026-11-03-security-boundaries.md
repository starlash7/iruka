# 보안 점검의 경계와 잔여 위험

- 사용자 보안 점검 요청에 따라 코드·의존성·로컬 합성 공격을 검증하고 확인된 경계를 수정했다.
- 기존 Privy 등록 보류와 유료 모델/배포 금지는 유지한다. 실제 사용자 자료·비밀값을 공격 증거로 읽지 않는다.
- HTTP 기본 상한은 로컬 보호를 위한 보수적 값이다. 운영 프록시 신뢰·분산 제한·계정별 모델 비용 정책의 승인을 대신하지 않는다.
- 비공개 프롬프트 복사 방어는 완전한 기밀성 보장이 아니다. 모델에는 코드·DB·지갑 도구 권한을 주지 않는다.
- npm audit 잔여 경고는 출시 전 과제다. 이를 무시하는 면제나 승인으로 기록하지 않는다. 기존 선택적 지갑 기능은 보존한다.
- SDK 하위 CJS/ESM·Zod 메이저 API를 무검증 강제 교체하지 않고, 실제 호환 검증과 상위 SDK 대응을 요구한다.
- 소스 점검·모의 토큰/모델·로컬 DB의 테스트는 실제 Privy/운영 PostgreSQL/유료 LLM 보안 인증이 아니다.
