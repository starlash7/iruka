- 사용자 최신 소유권(discover + chat UI)이 과거 A/C 배정보다 우선.
- 공유 파일은 변경 요청만. 독립 preview에서 실제 컴포넌트와 명시적 fixture를 실행.
- 02 핑크 전역 토큰 반영은 공통 담당에게 요청. feature 내부에는 동일 팔레트 적용.
- 모델 가격/무료 크레딧 정책은 D 정본. 임의 가격/랭킹/인기 수치 생성 안 함.

## 후속 브랜드·인증 결정
사용자 요청으로 자주색 채움을 연한 핑크로 변경하고 기존 파란 돌고래를 복원했다.
Privy 지갑·Google·이메일 로그인 허용으로 이전 Google/이메일 전용 제한을 대체한다.
자동 지갑 생성은 계속 off, 사용자 식별은 Privy DID를 유지한다.
공통 변경 요청과 실제 검증 범위는 docs/pivot/requests/reader-brand-wallet.md 참고.

## 기존 에셋 재사용
사용자 요청에 따라 원본 커밋 89c4596에서 프로필 얼굴 스프라이트, 계정 캐릭터,
바다 배경과 계정/지갑 아이콘을 복원하고 기존 워드마크를 다시 표시한다.
연결 주소는 Privy user.wallet에서만 읽으며 브라우저 저장 주소로 연결을 주장하지 않는다.
로그인/로그아웃 성공 시 화면을 재로드하여 이전 계정의 대화 캐시를 남기지 않는다.

## 기존 계정 구조 재사용
사용자 첨부 3개 화면과 후속 지시에 따라 기존 계정 배너, 네트워크,
Privy 잔액/주소/입출금과 설정을 축소하지 않고 재사용한다.
인벤토리는 사용자 선택에 따라 AI 작품·대화 보관함으로 전환한다.
현재 API 계약의 대화 목록으로 대화한 작품/개별 대화를 표시하며,
별도의 북마크 저장 계약이나 가짜 보관 기록을 만들지 않는다.
기존 카드 로컬 저장소는 변경하거나 삭제하지 않는다.
