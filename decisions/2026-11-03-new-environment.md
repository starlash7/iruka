# 새 환경 구성

사용자는 기존 환경이 없으며 새 구성이 필요하다고 응답했다.
기존 Privy Google/이메일 OTP·선택적 지갑 및 PostgreSQL 호환 스키마를 유지한다.
로컬은 PGlite 파일 DB를 먼저 구성한다. 원격 DB 사업자/지역/유료 요금은 결정하지 않는다.
실제 모델 어댑터는 기존 OpenAI gpt-5.4-mini를 유지하되 실제 호출을 활성화하지 않는다.
Privy 앱 ID/검증 공개키, 실제 Google/이메일 활성화·origin, 모델 안전 정책/한도/크레딧 정책은 외부 입력으로 남긴다.
약관 원문·개인정보 처리 정책·동의 버전이 확정되지 않아 동의 완료를 표시하거나 기록하지 않는다.
