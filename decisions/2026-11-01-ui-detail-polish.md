# UI detail polish decisions

- 기존 작품 에셋 대신 새 캐릭터를 생성하지 않는다. 새 생성 이미지는 작품 탐색을 설명하는 사람 없는 책/문 모티프 한 장으로 한정한다. 원본 작품 및 브랜드 보존.
- 공통 헤더에서 발견/검색/랭킹 중복 탭 대신 현재 위치를 표시한다. 탐색 메뉴는 사이드바/모바일 하단에 유지하며 찜 보관함은 사이드바에도 노출한다.
- 선택적 네트워크 메뉴는 계정 영역에서 유지한다. 탐색/작품/스튜디오에서는 작품과 계정 이동에 집중한다. 지갑 기능·인증·서버 API 변경 없음.
- 공개 작품이 두 개 이하일 때 데스크톱 카드는 표지+본문 두 열 카드로 표시한다. 데이터 복제나 가짜 랭킹/수치는 추가하지 않는다.
- 스튜디오 이미지 도구를 전용 탭으로 이동하고 초안 저장/발행 바를 고정한다. 복구·버전 고정·미리보기·발행 검증 규칙은 유지한다.
- 페르소나 비로그인 시 전체 계정·지갑 화면을 중복 렌더링하지 않고 공통 로그인 안내를 쓴다. 계정 키 변경 시 데이터 컴포넌트를 다시 마운트한다.
- 실제 크레딧 라우트는 src/features/wallet/index.tsx이다. 미사용 features/credits/CreditsPage.tsx는 수정하지 않고 실제 WalletView만 시각 개선한다.
- 실제 DB/로그인 검증 제외는 계속 적용한다. QA 서버는 인메모리 HTTP fixture와 테스트 세션만 사용한다. 모델/지갑 실행·유료 API·배포 없음.
