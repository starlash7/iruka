# 핑크 브랜드와 intro 버튼 효과
사용자 요청에 따라 현재 제품의 Iruka 에셋을 핑크 톤으로 통일한다.
돌고래 SVG는 원래 경로와 하이라이트를 유지하면서 색상만 변경한다.
기존 비트맵 워드마크/계정 배경/Iruka 아이콘은 원본 보존을 위해 표시 단계에서
CSS 색상 필터를 적용한다. 캐릭터 얼굴, 작품 커버, 체인/통화 식별 이미지는 제외한다.
89c4596의 iruka-entry-action-scan(4.8초), 유리 테두리, hover/active 반응을 재사용한다.
주요 CTA에는 스캔, 보조 버튼에는 얕은 입체감과 눌림을 적용한다.
작은 버튼의 글자 대비, disabled 및 reduced-motion을 유지한다.
