# 기존 Iruka 계정 기반 복원

사용자 첨부 화면과 최신 요청이 이전 최소 계정 화면 범위보다 우선한다.
기존 구현 89c4596을 기반으로 네트워크 선택, Privy 지갑 패널, 실제 잔액,
주소 복사, 입출금 진입점, 프로필 설정과 계정 배너를 유지한다.
AI 탐색/채팅은 별도 기능으로 연결하며 기존 계정을 새 간이 화면으로 대체하지 않는다.
GIWA/Monad 데이터는 네트워크별로 분리한다. 테스트 크레딧과 지갑 잔액을 합치지 않는다.
사용자 확정: 카드 인벤토리는 AI 작품·대화 보관함으로 변경한다. 기존 카드 저장소는 변경/삭제하지 않는다. 대화 목록에서 작품을 중복 제거해 보여주며 실제 대화로 이동한다.
자금 전송을 구현하더라도 검증 과정에서 실제 전송하거나 서명하지 않는다.
