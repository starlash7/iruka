# 스튜디오·시드 설계

기준 e67418a 및 최신 사용자 요청. 공유 계약 WorkDraftInput/CreatorWorkDto/StudioService와 공통 UI를 사용한다.
한국어 목록·탭 에디터, 구조화 필드, 자동 저장, 공개 프롤로그 미리보기, 발행을 구현한다.
초안은 server/studio 소유 SQL의 별도 테이블에 저장하여 발행된 works 메타데이터를 바꾸지 않는다.
revision 조건부 저장으로 여러 탭의 덮어쓰기를 거부한다. 발행은 작품 잠금 아래 새 work_versions를
생성하고 works 메타데이터를 함께 갱신한다. 기존 DB 불변 trigger와 대화 version FK를 재사용한다.
자산은 작품·작성자에 묶인 서버 등록 레코드다. 이번에는 업로드 없는 placeholder만 생성하며
임의 URL/다른 작품 자산은 거부한다. 발행 버전에 코드 매핑도 보존한다.
HTTP handler는 api/studio 소유 경로에 제공하며 공통 router/dev 연결은 인계한다.
공통 파일·패키지·기존 migration은 수정하지 않는다. studio migration은 별도 runner를 제공한다.
원본 crack 저장소의 실제 원고를 읽어 공개 필드와 비공개 설정으로 이식한다. 이미지 바이너리는
포함하지 않고 출처·변환·검수 한계를 기록한다. 성인 관련 필드/선택지, 유료 호출, 배포는 제외한다.
검증은 실제 PGlite DB 권한·불변성·경합·공개 경계, HTTP 인증, 필드 제한/임포터, seed 재실행,
전체 테스트/빌드와 desktop/mobile 로컬 브라우저 확인이다.
