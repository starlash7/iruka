# 통합 작품 탐색
독자는 작품의 인물/장르/상황으로 선택한다. 캐릭터/스토리의 내부 mode 및 검색
파라미터는 보존하되 상단 메뉴와 카드에서 제품을 둘로 나누지 않는다.
홈은 검색 → 실제 응답 태그 → 공개 작품 목록. 태그별 중복 목록과 추천 주장은 제거.
검색의 작품 유형은 보조 필터이며 q/tag/mode를 함께 유지한다. 태그 해제는 나머지
필터를 유지한다. 태그 화면에도 검색을 제공한다.
카드는 제목 두 줄, 소개 두 줄, 태그 두 개와 원본 표지/실패 대체 표면을 제공한다.
상세는 원문 소개와 인물, 첫 시작 상황을 읽고 기존 대화 시작 시트로 이동한다.
새 API/랭킹 알고리즘/데이터 필드/목업 운영 대체는 추가하지 않는다.
