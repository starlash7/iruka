# 보안 점검과 확인된 취약점 수정

승인: 사용자의 전체 보안 점검 요청(2026-11-03). Privy 등록 보류 유지.

범위: 현재 브랜치의 코드·의존성·로컬 HTTP 공격 재현, 인증/소유권, 공개 투영,
입력/이미지 제한, AI 프롬프트/출력 경계, 요청 남용, Git/개발 서버 비밀값 경계.
실제 개인정보/비밀값은 출력하거나 증거에 넣지 않는다. 타 플랫폼/운영 서버 공격,
실제 유료 모델·배포·데이터 삭제는 제외한다.

확인: Vite가 합성 canary를 `.context`와 `docs/internal`의 일반 URL 및 `/@fs` 경로에서
인증 없이 200으로 제공했다. 실제 DB나 비밀 파일을 읽지 않고 이 경계 실패를 재현했다.
해당 디렉터리와 환경 파일/키의 정적 제공을 차단하고 워크스페이스 밖 접근도 제한한다.

HTTP 경계에 요청 속도/동시 처리·본문 사전 크기/수신 시간 제한, Origin 검사,
민감 응답 보안 헤더를 추가한다. 소켓 주소를 사용하고 위조 X-Forwarded-For를 신뢰하지 않는다.
로컬 프로세스 제한은 분산 운영 레이트 리미터/계정별 모델 비용 정책을 대체하지 않는다.

AI: 모델은 도구/DB/지갑 권한을 갖지 않으며 서버만 소유권·모델/크레딧 정책을 판단한다.
비공개 긴 텍스트의 부분 복사·보이지 않는 문자 삽입 우회를 보완하고, 출력이 검사되기 전에
클라이언트로 보내지 않는 경계를 회귀 검증한다. 프롬프트 유출 완전 방지로 표현하지 않는다.

의존성: npm audit와 공개 advisory를 대조한다. 호환 범위 패치를 우선하고 강제 메이저
변경/SDK 기능 삭제로 경고 숫자를 감추지 않는다. 남는 경고/도달 가능성/운영 미검증을 기록한다.

검증: 합성 공격 회귀 테스트, 권한·정산 기존 테스트, 전체 npm test/build, audit 재실행.
보안 보고서/체크리스트/HANDOFF에 수정 및 잔여 위험을 남긴다. 현재 브랜치/기존 Draft PR 사용.
