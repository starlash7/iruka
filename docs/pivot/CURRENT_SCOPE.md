## 현재 단계 — 후속 A–D 개발과 통합 준비

아래 Wave 01/02 항목은 단계별 기록이다. 현재 구현·검증 상태는
[INTEGRATION.md](INTEGRATION.md)를 따른다. 탐색/스튜디오/채팅/테스트 크레딧의
실제 API를 연결한다. 유료 모델 호출·배포·main 병합은 하지 않는다.

스토리 중심 소개와 통합 작품 탐색을 따른다. 캐릭터 단독 대화도 지원하며
내부 character/story 타입·기존 데이터는 제거하지 않는다. 탐색·제작 화면의
새 흐름은 후속 작업이며 문서 변경만으로 앱 구현이 완료된 것은 아니다.
현재 A=모델, B=스튜디오/이미지, C=페르소나, D=탐색 UI다.
이전 A–D(특히 D=크레딧) 기록과 구분한다. 소유권·대기 요청은
[통합 계획](../../plans/integration-next.md)을 따른다.

후속 사용자 승인([기록](requests/reader-brand-wallet.md))에 따라 흰색·핑크 UI,
Privy Google/이메일/지갑 로그인과 복원된 계정·지갑 기능을 보존한다.
지갑 생성/송금은 사용자 명시 동작이며 대화 이용 조건이 아니다.
실제 상품 결제·크레딧 구매·정산과 성인 기능은 계속 제외한다.
GIWA 장부 앵커링은 이전 크레딧 담당(D)의 후속 범위 결정에 따라 보류한다.
모델과 테스트 크레딧 정책은 로컬 명시 설정으로만 활성화하며, 실제 모델/운영
안전 정책과 원격 DB 검증 없이 출시 완료로 표현하지 않는다.

## 제품 목표
한국어 AI 캐릭터·스토리 작품 탐색, 제작, 대화. Privy Google 로그인과
이메일 인증(이메일 OTP 로그인)을 사용한다. Google 사용자에게 추가 이메일
연결이나 외부 지갑 연결, SIWE 서명을 이용 조건으로 요구하지 않는다.
계정 키는 Privy DID이며 지갑 주소가 아니다.

무료 테스트 크레딧 지급·예약·정산·실패 반환은 로컬 통합 검증됐다.
크레딧은 구매·양도·환전·출금 불가이며 DB 원장이 정본이다.
GIWA 앵커링은 보류 상태다. 실제 대화 내용·이메일·계정 식별자를 체인에 쓰지 않는다.

## 현재 제외와 미확정

- 성인 콘텐츠·성인인증, 상품 결제·정산·신고 관리자, 과거 TCG 기능 재도입 제외.
- main 병합·배포·유료 API 호출 금지. 승인된 기존 선택적 지갑 기능은 보존.
- 실제 모델·안전 정책, 저장소, 크레딧 지급량·주기·모델별 차감 정책은 결정 필요.
- 운영 인증·원격 DB·상시 작업자·데이터 보존/삭제는 미검증 또는 미확정.
