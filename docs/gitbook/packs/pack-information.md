# Pack Information

Iruka packs are themed collectible drops with visible supply, price, odds, and estimated value ranges.

## Example Pack Types

| Pack | Category | Purpose |
| --- | --- | --- |
| Girl Group Iruka Pack | K-pop | Neutral idol collectible pack |
| Boy Group Iruka Pack | K-pop | Neutral idol collectible pack |
| Premium Idol Drop | K-pop | Higher-value curated inventory |
| Rookie Idol Drop | K-pop | Emerging collection inventory |
| TCG Slab Pack | TCG | Graded card or slab inventory |

## Pack Naming Rule

Pack names should not use third-party artist, agency, label, game, or brand names as Iruka-owned product branding unless Iruka has the appropriate rights or partnership.

Use specific item names only inside actual marketplace listing details, vault item details, or inventory records where they identify a genuine physical product.

## Pack Lifecycle

1. Inventory is sourced and verified.
2. Items are grouped into a pack pool.
3. Pack price, odds, and value bands are published.
4. Users pull packs until supply is exhausted.
5. Revealed items move into vault, marketplace, or shipping flows.
