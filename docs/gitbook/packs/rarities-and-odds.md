# Rarities and Odds

Iruka uses five rarity tiers.

| Tier | Purpose |
| --- | --- |
| Common | Baseline collectible items |
| Rare | Better condition, demand, or scarcity |
| Epic | Higher value chase range |
| Legendary | Very scarce premium pulls |
| Iruka | Top chase tier |

## Disclosure Standard

Each public pack should disclose:

- Pack price
- Remaining supply
- Rarity tiers
- Odds for each tier
- Estimated value range per tier
- Redemption and shipping policy
- Refund and cancellation policy

This keeps the product understandable and reduces disputes around random pack outcomes.
