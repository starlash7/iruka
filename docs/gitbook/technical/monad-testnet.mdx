## Deployment Boundary

Iruka's Metropolis scope brings the existing pack-opening flow to Monad
Testnet. GIWA remains the default deployment and its historical receipts remain
GIWA evidence. The header selects either testnet within the same deployment. Switching
reloads the app so wallet configuration, RPC clients and network-specific state
change together. The interface does not move funds or inventory between chains.

## Configuration

The browser needs its Monad contract address and RPC. Keeper configuration,
deployer credentials and the manifest encryption key remain server-only.
The Monad manifest uses independent draw seeds and commitments. Requests,
collection records and fulfillment leases are isolated from GIWA.

The browser triggers `/api/monad/fulfill`, then confirms the actual contract
result and matching event before Reveal. Scheduled recovery operates one initial
Debut batch; additional batches need a recovery design that resolves global
request IDs from events.

fulfillment or recovery API. The production cron invoked `/api/monad/recover`
