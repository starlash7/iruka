## 요청이 지나가는 경로

```text
React / Vite 화면
  → HTTP API + Privy 토큰 검증
  → 작품 · 스튜디오 · 대화 서비스
  → DB 기록 / 크레딧 원장
  → 모델 어댑터 → 출력 검사 → 응답 확정
```

화면은 공개 탐색 응답과 인증된 제작·대화 API를 사용합니다. 대화 응답은 SSE 이벤트로 전달합니다. 모델과 안전 정책이 설정되지 않으면 생성 기능을 사용할 수 없도록 처리합니다.

## 인증과 데이터 경계

서버는 Privy JWT의 서명·발급자·앱 대상·유효기간 등을 검증하고 `sub`의 Privy DID로 계정을 식별합니다. 작품 편집과 대화·크레딧 조회는 소유권 확인을 거칩니다.

공개 작품 응답은 허용된 필드만 선택합니다. 비공개 프롬프트와 숨김 설정은 공개 응답에서 제외하고 생성용 입력은 서버에서 조립합니다. 모델 출력 검사는 일부 원문 반복과 잘못된 제어 코드를 막지만 모든 유출·추론 공격을 방지한다는 보장은 아닙니다.

## 구현과 운영 검증의 차이

| 구분 | 확인된 범위 | 남은 검증 |
| --- | --- | --- |
| 로컬 DB | 격리된 PGlite 기반 테스트와 트랜잭션 | 원격 PostgreSQL 동시성·운영 구성 |
| 인증 | 토큰 검증·권한 거부 테스트 | 실제 Google·이메일 로그인 전체 흐름 |
| 모델 | 고정 응답 및 OpenAI Responses 어댑터의 테스트 전송·실패 복구 | 실제 LLM 호출·품질·사용량 정책·안전성 |
| 작업 실행 | 만료 요청 복구와 별도 활성화가 필요한 요약 코드 | 운영 환경에서 지속 실행되는 작업자 |
| 이미지 | 로컬 파일 저장·소유권 검사·인증된 대화 이미지 조회 | 원격 저장소·수명주기·운영 비용 |

로컬 테스트 모델은 `LOCAL_TEST_CHAT=1`을 명시할 때만 활성화합니다. production 또는 Vercel 환경에서는 이 설정을 거부합니다. 로컬 설정이 실제 인증을 우회하지는 않습니다.

## 아직 정하지 않은 정책

데이터 보존기간, 계정 삭제와 영구 삭제 절차, 운영 암호화 구성, 보안 감사 여부는 이 문서에서 확정하지 않습니다. 현재 대화·메시지의 삭제 상태 기록을 모든 저장본의 즉시 삭제로 해석해서는 안 됩니다.

Docs의 비공개 접근 제한은 별도 운영 설정입니다. `robots.txt`와 검색 엔진 메타태그는 접근 제어가 아니며, 이번 문서 변경은 기존 접근 제한을 해제하지 않습니다.
