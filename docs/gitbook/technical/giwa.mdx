현재 크레딧 잔액과 거래의 기준은 서버 DB 원장입니다. **GIWA 장부 앵커링은 보류 상태**이며, 이 플랫폼의 새 장부 계약 배포나 앵커 거래가 확인되었다고 주장하지 않습니다.

## 검토 중인 역할

향후 앵커링을 추진한다면 원장 기록의 포함 여부와 무결성을 확인하는 용도로 검토합니다. 앵커는 대화 내용의 진실성, 모델 품질이나 결제·정산 완료를 보장하는 기능이 아닙니다.

대화 원문·이메일·계정 식별자를 체인에 기록하지 않는 방향입니다. 실제 구현과 검증 방법은 후속 결정이 필요합니다.

## 현재 지갑과의 구분

계정의 선택적 GIWA·Monad 네트워크 조회 및 전송 화면은 크레딧 장부 앵커링과 별개입니다. 지갑 잔액 조회가 된다고 장부 앵커가 배포되었거나 크레딧이 온체인 자산이라는 뜻은 아닙니다.

과거 팩 컨트랙트·민팅·거래 영수증은 과거 제품의 기록입니다. 현재 스토리 플랫폼의 배포·정산·사용 실적으로 사용하지 않습니다.
