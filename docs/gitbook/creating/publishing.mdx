## 저장과 발행

**저장**은 제작자 초안을 갱신합니다. 이미 발행한 공개 내용은 초안 저장만으로 바뀌지 않습니다.

**발행**은 입력과 이미지 소유권을 검사한 뒤 새 버전을 만들고 작품을 공개합니다. 공개 정보와 비공개 설정을 함께 확인하세요. 현재 편집 화면은 별도의 공개 범위 선택이나 발행 취소 기능을 제공하지 않습니다.

## 발행 전 확인

- 작품 이름, 메인 프롬프트, 시작 상황 이름과 프롤로그를 채웁니다.
- 현재 구현에서 캐릭터 모드를 선택했다면 사용자·답변이 있는 예시 대화가 필요합니다.
- 설정의 인물·시작 상황 연결과 이미지 코드가 올바른지 확인합니다.
- 저장 실패나 충돌 메시지가 없는지 확인합니다.

다른 저장 내용과 충돌하면 서버가 오래된 편집본의 저장·발행을 거부합니다. 다시 열어 최신 내용을 확인한 뒤 수정하세요.

## 진행 중인 대화는 어떻게 되나요?

발행 버전은 변경 불가능한 기록으로 저장합니다. 새 대화는 최신 발행 버전에서 시작하며 기존 대화는 시작 당시 버전에 고정됩니다. 작품의 제목이나 모드를 바꾸어 새로 발행해도 이미 진행하던 대화의 기준은 유지됩니다.

발행 기록을 읽는 서버 기능은 있지만, 과거 버전으로 되돌리는 관리 화면이 완성되었다고 안내하지 않습니다.
