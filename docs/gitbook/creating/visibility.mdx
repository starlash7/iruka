## 공개 작품에 담기는 정보

작품 이름·소개·표지·태그·모드, 한 줄 소개와 플레이 가이드, 등장인물의 이름·이미지, 시작 상황의 제목·프롤로그·첫 대사·추천 답변이 공개 정보입니다. 화면에서 접혀 있거나 일부만 보이더라도 공개 응답에 포함되는 필드입니다.

## 제작자용 비공개 설정

메인 프롬프트, 인물의 상세 소개·말투, 예시 대화, 숨김 시작 상황, 로어북, 출력 규칙·상태창 템플릿, 엔딩 조건은 공개 작품 API에서 제외합니다. 제작자 편집 API는 서버에서 작품 소유자를 확인합니다.

로어북의 **숨김** 체크를 해제해도 현재 공개 API가 로어북 원문을 반환하는 것은 아닙니다. 로어북 전체는 비공개 설정에 저장됩니다.

## 모델 출력은 별도의 경계입니다

비공개 설정은 응답 생성을 위해 서버에서 모델 입력에 포함됩니다. 설정 원문 반복을 차단하는 검사와 출력 처리 코드가 있지만, 우회 표현이나 추론을 통한 프롬프트 유출까지 절대 방지한다고 보장하지 않습니다.

엔딩 제목이나 등록된 이미지처럼 결과에 보여 주도록 설정한 정보는 대화 출력으로 표시될 수 있습니다. 비공개 설정에 비밀번호·키·민감한 개인정보를 넣지 마세요.
