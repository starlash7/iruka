스튜디오는 로그인한 제작자가 자신의 작품 초안을 작성하는 공간입니다. **내 작품**에서 작품을 만들거나 기존 작품의 편집 화면을 엽니다.

## 작성 순서

1. **기본 정보**에서 작품 이름, 모드, 소개와 태그를 적습니다.
2. **프롬프트**와 **등장인물**에서 이야기의 방향과 인물의 성격을 설정합니다.
3. **시작 상황**에서 독자가 처음 볼 장면과 첫 대사를 적습니다.
4. 필요에 따라 예시 대화, 설정집, 상태창·출력, 엔딩을 작성합니다.
5. **미리보기**를 확인하고 저장 상태를 확인한 뒤 발행합니다.

수정 후 자동 저장을 시도하며 **저장** 버튼으로 직접 저장할 수도 있습니다. 저장 실패가 표시되면 완료된 것으로 간주하지 말고 내용을 확인하세요.

## 미리보기의 범위

현재 미리보기는 소개·시작 상황·등록 이미지 표시를 확인하는 화면입니다. 실제 LLM과 대화해 보는 테스트 채팅은 아닙니다.

이미지 탭은 작품 소유의 이미지 코드와 슬롯을 등록합니다. 실제 파일 업로드·저장소 연결은 아직 준비 중이며, 등록만으로 이미지가 업로드되지는 않습니다. 기존 Iruka 자산이나 사용 권한이 확인된 자료만 사용하세요.
