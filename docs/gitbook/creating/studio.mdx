스튜디오는 로그인한 제작자가 자신의 작품 초안을 작성하는 공간입니다. **내 작품**에서 **새 작품**을 누르거나 기존 작품의 편집 화면을 엽니다. 한 명의 캐릭터와 시작하는 이야기부터 여러 인물이 등장하는 세계까지 같은 편집 흐름으로 구성합니다.

## 작성 순서

1. **기본 소개**에서 작품 이름, 이야기 구성, 비공개 이야기 방향, 소개와 태그를 적습니다.
2. **등장인물**에서 인물의 이름과 성격을 설정합니다.
3. **시작 상황**에서 독자가 처음 볼 장면과 첫 대사를 적습니다.
4. 필요에 따라 **고급 설정**을 열어 예시 대화, 설정집, 상태창·출력, 엔딩을 작성합니다.
5. **미리보기**를 확인하고 저장 상태를 확인한 뒤 발행합니다.

수정 후 자동 저장을 시도하며 **초안 저장** 버튼으로 직접 저장할 수도 있습니다. 저장 실패가 표시되면 완료된 것으로 간주하지 말고 내용을 확인하세요.

## 필요한 만큼 설정하기

기본 소개 → 등장인물 → 시작 상황 → 미리보기 순서로 작성합니다. 세계관 설명이 필요하면 고급 설정의 설정집을, 진행 상태나 결말 표현이 필요하면 상태창·엔딩을 펼쳐 추가하세요.

## 미리보기의 범위

현재 미리보기는 소개·시작 상황·등록 이미지 표시를 확인하는 화면입니다. 실제 LLM과 대화해 보는 테스트 채팅은 아닙니다.

표지와 등장인물 이미지를 파일로 등록할 수 있습니다. 로컬 개발 서버는 별도의 로컬 이미지 저장소를 사용하며, 운영 저장소는 아직 연결하지 않았습니다. 고급 설정의 이미지 코드는 슬롯을 등록하는 기능으로, 코드 등록만으로 파일이 업로드되지는 않습니다. 기존 Iruka 자산이나 사용 권한이 확인된 자료만 사용하세요.
