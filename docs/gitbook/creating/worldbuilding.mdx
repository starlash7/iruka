## 시작 상황

한 작품에 최대 5개를 작성할 수 있습니다. 시작 이름과 프롤로그는 독자가 장면을 고를 때 보는 정보입니다. 첫 대사와 최대 3개의 추천 답변도 공개 정보에 포함됩니다. 숨김 시작 상황은 모델에 전달할 배경으로 따로 적습니다.

발행하려면 시작 상황이 하나 이상 필요하며 각 시작 상황의 이름과 프롤로그를 채워야 합니다.

## 등장인물과 예시 대화

이름과 이미지는 공개 정보, 상세 소개와 말투는 비공개 설정입니다. 예시 대화에는 사용자 문장과 기대하는 답변을 짝으로 적습니다. 캐릭터 모드는 발행할 때 비어 있지 않은 예시 대화가 하나 이상 필요합니다.

## 로어북 — 설정집

설정집에는 카테고리, 키워드, 내용, 우선순위, 상시 적용 여부를 적습니다. 상시 항목은 기본 문맥에 포함하고, 나머지는 최근 대화와 현재 입력의 키워드에 맞는 항목을 선택합니다.

선택은 우선순위와 문맥 예산의 영향을 받습니다. 모든 항목이 매번 모델에 전달되는 것은 아닙니다. 키워드는 정규식이 아니라 문자 일치 기준으로 비교합니다.

## 출력 표시 코드

다음은 작성 형식 예시입니다. 실제 모델의 출력 성공을 보장하는 샘플은 아닙니다.

```text
{{user}}님, 도서관에 오신 것을 환영합니다.
{{char}}가 창가를 가리킵니다.
{{img:library}}
{{ending:quiet_evening}}
```

사용자·첫 등장인물 이름을 치환하고, 등록된 이미지 코드와 엔딩 ID를 확인해 표시합니다. 이미지는 작품에 등록되고 실제 URL이 있는 자산만 표시할 수 있습니다. 미등록 코드나 잘못된 제어 표기는 그대로 노출하지 않도록 처리합니다.
