Iruka는 한국어로 캐릭터와 대화하고 이야기를 이어 가고 싶은 독자, 직접 등장인물과 세계관을 만들고 싶은 제작자를 위한 플랫폼입니다.

작품을 **탐색**한 뒤 마음에 드는 시작 상황을 골라 **대화**하거나, **스튜디오**에서 자신의 작품을 만들어 발행할 수 있습니다.

## 어떤 경험을 할 수 있나요?

- **캐릭터 모드**: 인물의 성격과 말투를 중심으로 대화를 이어 갑니다.
- **스토리 모드**: 상황과 여러 등장인물을 바탕으로 이야기를 진행합니다.
- **재생성과 분기**: 다른 응답을 선택하거나 특정 장면에서 새 대화를 시작합니다.
- **작품 제작**: 독자에게 보일 소개와 모델에 전달할 비공개 설정을 나누어 작성합니다.

## 지금의 개발 상태

탐색·스튜디오·대화·무료 테스트 크레딧은 코드에 연결되어 있으며 로컬 통합 테스트로 확인했습니다. 현재 로컬 모델은 **정해진 테스트 응답**을 반환합니다. 실제 LLM의 대화 품질이나 공개 서비스 운영이 검증되었다는 뜻은 아닙니다.

지갑 생성·충전·서명은 대화 이용 조건이 아닙니다. 사용 가능한 로그인 수단은 [계정 안내](/account/login), 아직 준비 중인 항목은 [로드맵](/roadmap)에서 확인할 수 있습니다.
