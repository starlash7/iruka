Iruka is a collectible vending, vault, and marketplace product for physical items.

## Core Flow

1. Choose a vending machine pack.
2. Pull and reveal a collectible.
3. Keep it vaulted, list it on the marketplace, or request shipment.

## What Iruka Does

- Lets users pull random collectible packs.
- Reveals an item with rarity, serial, estimated value, and vault status.
- Keeps eligible items in a verified vault record.
- Lets users list, sell, or request shipment from one product flow.

## Current MVP

- Vending machine pack pulls
- Rarity and odds display
- Reveal results
- Private vault actions for authenticated accounts
- Marketplace listing preview
- Privy login with external Solana wallets
- English and Korean product UI

## Important Positioning

Iruka does not imply official affiliation with an artist, agency, label, publisher, manufacturer, or grading company unless that relationship exists.

Public pack names stay neutral. Marketplace and vault records may use third-party names only when needed to identify genuine physical items.
