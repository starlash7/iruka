Iruka는 한국어 AI 캐릭터·스토리 작품을 탐색하고 만들고 대화하는 플랫폼으로
전환 중입니다. 현재 코드에는 Privy Google·이메일 로그인과 최소 계정 화면이 있습니다.
새 탐색·제작·채팅 화면은 다음 단계입니다.

무료 테스트 크레딧 지급·차감과 GIWA 테스트넷 장부 앵커링을 계획합니다.
현재 잔액/앵커 계약/새 체인 영수증은 구현하거나 배포하지 않았습니다.

외부 지갑 연결이나 SIWE 서명은 서비스 이용 조건이 아닙니다.
성인 콘텐츠·19등급·성인인증, 실제 결제·환불·크리에이터 정산·신고 관리자
기능은 범위에서 제외합니다. 기존 팩·가챠·실물 보관·거래·입출금 기능은 종료된
코드 경로이며 과거 문서와 공개 증거는 저장소 docs/archive/tcg/에 보관합니다.

정확한 개발 범위는 저장소 docs/pivot/CURRENT_SCOPE.md를 확인하세요.
