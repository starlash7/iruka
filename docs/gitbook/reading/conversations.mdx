## 메시지 보내기

대화 화면에서 메시지를 보내면 응답 생성이 시작됩니다. 생성 중인 내용은 확정 전 상태이며, 완료 결과를 확인해야 저장된 응답으로 볼 수 있습니다. 연결이 끊기면 기존 요청 상태를 확인해 중복 생성을 피하도록 처리합니다.

## 대화 보관함

**내 대화**에서 이어갈 대화를 선택하거나 이름과 폴더를 변경할 수 있습니다. 폴더를 만들고 이름을 바꾸거나 삭제할 수 있으며, 폴더를 삭제하면 안의 대화는 **미분류**에 남습니다. 대화 목록은 50개씩 추가로 불러올 수 있습니다.

대화 삭제는 확인 후 처리하며 삭제한 대화는 보관함에서 다시 이어갈 수 없습니다. 응답을 생성 중이면 생성을 마치거나 중단한 뒤 삭제합니다. 이름이나 폴더를 바꾸어도 처음 선택한 작품 버전과 페르소나는 유지됩니다.

## 메시지 검색과 읽기 설정

상단 **검색**으로 현재 선택한 분기의 메시지 내용을 찾습니다. 검색어는 문자 그대로 비교하고 일치하는 메시지를 강조하며, 위·아래 버튼 또는 Enter·Shift+Enter로 이동합니다. 다른 분기의 내용은 해당 분기를 선택한 뒤 검색하세요. Escape로 검색을 닫을 수 있습니다.

**대화 설정 → 읽기 설정**에서 글자 크기와 줄 간격을 조절합니다. 설정은 이 기기에 저장하며, 브라우저에서 저장을 허용하지 않으면 현재 화면에만 적용합니다. 검색과 읽기 설정은 응답을 생성하거나 크레딧을 사용하지 않습니다.

## 다른 응답과 경로 선택하기

| 동작 | 결과 |
| --- | --- |
| 재생성 | 마지막 AI 응답에 대해 같은 사용자 메시지에서 새 응답을 만듭니다. |
| 이전·다음 | 같은 메시지에서 갈라진 응답 중 하나를 선택합니다. |
| 사용자 메시지 수정 | 기존 내용을 덮어쓰지 않고 같은 부모 아래 새 메시지를 만듭니다. |
| 여기서 분기 | 선택한 지점까지의 경로를 복사해 별도 대화를 만듭니다. |
| 메시지 삭제 | 해당 메시지와 그 뒤로 이어진 분기를 삭제 상태로 바꿉니다. |

분기된 대화는 기존 작품 버전과 페르소나 정보를 유지하고 고정 메모를 복사합니다. 응답 생성 중에는 수정·삭제·분기 같은 동작이 제한됩니다.

## 크레딧과 실패 처리

새 메시지의 응답 생성과 재생성은 크레딧 예약·정산 대상입니다. 메시지 수정, 기존 응답 선택과 대화 분기 자체는 모델을 호출하지 않습니다. 실패·취소 시 예약분을 반환하는 처리와 중단된 요청을 복구하는 코드가 있습니다. 운영 환경에서의 복구 실행은 별도 검증이 필요합니다.
