## 페르소나

페르소나는 대화 속에서 사용할 이름과 설명입니다. 시작 화면은 계정에 저장된 페르소나를 조회해 선택할 수 있도록 되어 있으며, 선택하지 않고 기본 페르소나로 시작할 수도 있습니다. 서버는 다른 사람의 페르소나를 사용할 수 없도록 소유권을 확인합니다.

대화를 시작할 때 이름과 설명을 복사해 보관하므로, 원본 페르소나를 나중에 바꾸어도 진행 중인 대화에 자동 반영되지 않습니다.

**내 페르소나**에서 이름과 소개를 생성·수정·삭제할 수 있습니다. 이름은 50자, 소개는 500자 이내로 작성합니다. 삭제한 페르소나는 새 대화에서 선택할 수 없지만 기존 대화에 복사된 이름과 설명은 유지됩니다. 이 삭제는 과거 대화 데이터의 영구 삭제를 뜻하지 않습니다.

## 고정 메모

대화의 **고정 메모**를 열어 기억할 내용을 적고 **메모 저장**을 누릅니다. 현재 화면의 입력 한도는 2,000자입니다. 빈 내용으로 저장하면 해당 메모를 지웁니다.

메모는 모델 입력에 포함할 참고 정보입니다. 언제나 정확하게 기억하거나 지시를 따르게 만드는 보장은 아닙니다. 비밀번호나 개인적인 비밀은 적지 않는 것이 좋습니다.

## 요약과 기억의 범위

서버에는 대화 요약 작업과 현재 분기에 맞는 기억을 선택하는 코드가 있습니다. 자동 요약은 기본적으로 꺼져 있으며 운영자가 별도로 활성화해야 합니다. 만료 요청 복구와 요약 모델 호출은 분리되어 있습니다. 실제 모델의 요약 품질과 운영 작업자의 지속 실행은 미검증이며, 모든 대화를 무제한 기억하는 기능으로 설명하지 않습니다.
