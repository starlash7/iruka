현재 목표는 **탐색 → 작품 선택/제작 → 대화** 흐름을 실제 서비스 환경에서도 검증하는 것입니다. 아래 상태는 코드와 로컬 확인을 기준으로 하며 공개 출시 일정은 정하지 않았습니다.

## 구현됨 — 코드와 로컬 테스트

- 발행된 공개 작품 탐색, 검색·태그·모드 필터와 성공 대화 기반 랭킹
- 스튜디오 초안 저장, 공개·비공개 필드 분리, 발행 버전과 대화 버전 고정
- 대화 생성, 재생성, 메시지 수정·선택·분기와 고정 메모
- 무료 크레딧의 서버 지급, 예약·정산·실패 반환과 중복 처리 방지
- 선택적 계정·지갑 화면과 대화 보관함

## 검증 중 — 공개 운영 전 확인

실제 Google·이메일·지갑 인증 전체 흐름, 실제 LLM 어댑터와 대화 품질·사용량 측정, 운영 안전 정책, 원격 PostgreSQL 동시성, API 호스팅과 복구·요약 작업자의 지속 실행을 확인해야 합니다.

## 계획됨 — 세부 범위와 정책 결정 필요

페르소나 생성·편집 화면, 이미지 업로드·저장소, 무료 크레딧 지급량·주기·차감 정책, 데이터 보존·삭제 정책은 후속 결정 또는 구현이 필요합니다. GIWA 장부 앵커링은 보류합니다.

## 현재 범위 밖

성인 기능, 실제 상품 결제·환불·크리에이터 정산, NFT·팩·실물 Vault·배송은 현행 기능으로 제공하지 않습니다. 공개 출시 날짜나 다음 기능의 제공 시점을 약속하지 않습니다.
