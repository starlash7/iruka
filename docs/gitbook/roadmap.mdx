Iruka는 캐릭터와 대화하며 이야기를 이어가는 경험을 중심으로, 인물 중심 대화와 여러 인물이 등장하는 이야기를 **작품**으로 함께 다룹니다. 현재 목표는 **탐색 → 작품 선택/제작 → 대화** 흐름을 실제 서비스 환경에서도 검증하는 것입니다. 아래 상태는 코드와 로컬 확인을 기준으로 하며 공개 출시 일정은 정하지 않았습니다.

## 구현됨 — 코드와 로컬 테스트

- 발행된 공개 작품 탐색, 검색·태그·모드 필터와 성공 대화 기반 랭킹
- 스튜디오 초안 저장, 공개·비공개 필드 분리, 발행 버전과 대화 버전 고정
- 대화 생성, 재생성, 메시지 수정·선택·분기와 고정 메모
- 무료 크레딧의 서버 지급, 예약·정산·실패 반환과 중복 처리 방지
- 선택적 계정·지갑 화면과 대화 보관함
- 작품별 이어하기·새 대화, 보관함 이름·폴더 관리와 대화 삭제
- 현재 대화 분기 메시지 검색, 기기별 글자 크기·줄 간격 설정
- 탐색 추가 불러오기, 비공개 찜 보관함과 발행자가 선택하는 제작자명 표시
- 페르소나 생성·수정·삭제와 기존 대화 설정 보존
- 기본 작성 단계와 고급 설정 분리, 이미지 코드 슬롯 업로드·교체와 발행 이미지 보존
- 공개 소개·갤러리·시작 장면 이미지와 확대 보기, 고정 인물 초상과 상태 카드
- 제작 이미지 목록·검색·일괄 등록·실패 재시도, 표지가 있는 작품 관리 목록
- OpenAI Responses 어댑터의 테스트 전송 검증 (실제 호출 비활성)

## 검증 중 — 공개 운영 전 확인

실제 Google·이메일·지갑 인증 전체 흐름, 실제 LLM 어댑터와 대화 품질·사용량 측정, 운영 안전 정책, 원격 PostgreSQL 동시성, API 호스팅과 복구·요약 작업자의 지속 실행을 확인해야 합니다.

## 계획됨 — 세부 범위와 정책 결정 필요

작품·태그 중심 탐색과 단계별 제작 화면은 통합했습니다. 실제 사용자 피드백을 바탕으로 탐색 분류와 제작 흐름을 더 검증할 예정이며, 기존 캐릭터·스토리 데이터는 유지합니다.

운영 이미지 저장소, 무료 크레딧 지급량·주기·차감 정책, 모델 안전 정책과 호출 예산, 데이터 보존·삭제 정책은 후속 결정 또는 구현이 필요합니다. GIWA 장부 앵커링은 보류합니다.

## 현재 범위 밖

성인 기능, 실제 상품 결제·환불·크리에이터 정산, NFT·팩·실물 Vault·배송은 현행 기능으로 제공하지 않습니다. 공개 출시 날짜나 다음 기능의 제공 시점을 약속하지 않습니다.
