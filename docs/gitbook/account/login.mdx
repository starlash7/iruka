## 대화와 작품의 주인은 계정입니다

현재 로그인 구성은 Google·이메일·지갑입니다. 이용 가능한 인증 수단은 해당 환경의 Privy 설정에 따라 달라집니다. 로그인 설정이 없으면 가짜 계정을 만들지 않고 준비 상태를 표시합니다.

계정 식별 기준은 **Privy DID**입니다. 서버는 요청의 토큰을 검증하고, 대화·페르소나·작품·크레딧의 소유권을 별도로 확인합니다. 브라우저에 로그인 화면이 보인다는 사실만으로 API 권한이 생기지는 않습니다.

## 계정에서 다시 이어 가기

계정의 보관함은 작품과 대화 목록을 보여 줍니다. 과거 실물 카드의 보관·소유 증명을 뜻하는 Vault가 아닙니다.

## 지갑은 선택 기능입니다

후속 승인으로 계정에 지갑 연결·명시적 생성 버튼, 네트워크 선택, 잔액 조회·주소 복사, 입출금 화면이 복원되어 있습니다. 로그인 때 자동 지갑을 만들지 않으며 생성·송금은 이용자가 직접 선택하는 동작입니다.

**지갑 생성·충전·서명은 대화 이용 조건이 아닙니다.** 지갑 잔액과 무료 테스트 크레딧은 별개이며, 입금으로 크레딧을 구매하는 흐름은 없습니다. 지갑 로그인을 스스로 선택한 경우의 인증 절차와 대화를 위한 필수 조건을 구분해야 합니다.

## 검증 범위

통합 기록에는 기존 Privy 세션 복원과 GIWA·Monad 잔액 조회 확인이 있습니다. 이번 Docs 작업에서 실제 OAuth·이메일 OTP, 새 지갑 생성·송금·서명을 다시 수행한 것은 아닙니다. 기능 코드가 존재하는 사실을 실제 전송 성공으로 표현하지 않습니다.
