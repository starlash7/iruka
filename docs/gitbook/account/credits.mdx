---
title: "무료 테스트 크레딧"
description: "잔액, 예약, 정산과 실패 반환"
---

테스트 크레딧은 응답 생성 흐름을 확인하기 위한 무료 단위입니다. 구매·양도·환전·출금할 수 없고, 지갑 자산과도 연결하지 않습니다. 서비스 지급량·주기·모델별 차감 정책은 아직 확정하지 않았습니다.

## 응답 하나를 처리하는 순서

| 단계 | 잔액에 미치는 영향 |
| --- | --- |
| 지급 | 서버가 지정한 지급 키로 크레딧을 추가합니다. |
| 예약 | 생성 전에 필요한 금액을 사용 가능 잔액에서 빼고 예약 상태로 둡니다. |
| 완료 정산 | 실제 차감값을 확정하고 예약분 중 남는 금액을 돌려줍니다. |
| 실패·취소 | 미완료 요청의 예약분을 반환합니다. |

완료 처리에서는 응답 저장과 원장 정산을 같은 트랜잭션으로 묶습니다. 예약보다 큰 금액을 완료 시점에 추가 차감하지 않습니다. 잔액이 부족하면 예약을 거부합니다.

## 중복 요청과 중단 복구

같은 지급 키·같은 내용의 지급은 반복해도 중복 지급하지 않습니다. 같은 생성 요청 키를 다시 처리할 때 완료 결과를 재사용하며, 예약·정산·반환도 중복 기록을 막습니다. 같은 키에 다른 내용이나 금액을 보내면 충돌로 거부합니다.

재생성은 별도의 새 요청이므로 예약 대상입니다. 연결이 끊겼다고 항상 즉시 반환되는 것은 아닙니다. 서버에는 만료된 실행 권한을 확인해 중단 요청을 복구하는 기능이 있으며, 운영 환경의 지속 실행은 별도 확인이 필요합니다.

## 로컬 테스트 값

명시적으로 로컬 테스트를 켠 환경에서는 계정당 한 번 100 크레딧을 지급하고 성공한 생성에 1을 차감합니다. **이는 개발용 고정값이며 무료 서비스 약속이나 확정 요금제가 아닙니다.**

DB 원장이 기준 기록입니다. 내역의 체인 검증 상태는 현재 `unverified`이며 [GIWA 앵커링](/technical/giwa)은 보류 중입니다.
