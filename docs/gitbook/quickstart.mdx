## 작품을 골라 대화하기

1. 탐색에서 작품을 고릅니다. 검색어나 관심 있는 장르·태그로 범위를 좁힐 수 있습니다.
2. 작품 상세에서 소개, 등장인물, 시작 상황과 플레이 가이드를 읽습니다.
3. 로그인한 뒤 **대화 시작**을 누릅니다.
4. 시작 상황, 사용할 수 있는 페르소나와 모델을 확인하고 **이 상황으로 시작**을 누릅니다.
5. 메시지를 보내고 응답을 확인합니다. 진행한 대화는 대화 목록이나 계정의 보관함에서 다시 엽니다.

<Note>현재 로컬 테스트 모델은 같은 정해진 응답을 반환합니다. 자연스러운 이야기 전개나 재생성 품질을 평가할 수 있는 실제 LLM은 아직 연결되지 않았습니다.</Note>

## 시작할 수 없을 때

| 화면 상태 | 확인할 내용 |
| --- | --- |
| 로그인할 수 없음 | 해당 환경에 Privy 설정이 필요한지 확인합니다. |
| 사용할 수 있는 모델이 없음 | 서버 모델·안전 정책 설정이 없는 상태입니다. 지갑 충전으로 해결되지 않습니다. |
| 테스트 크레딧 부족 | 남은 크레딧을 확인합니다. 크레딧 구매 기능은 제공하지 않습니다. |
| 작품이 보이지 않음 | 발행된 공개 작품만 탐색에 표시됩니다. |

제작자로 시작하려면 [스튜디오 안내](/creating/studio)를 따르세요.
