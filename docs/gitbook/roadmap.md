# Roadmap

This roadmap describes the near-term direction for Iruka.

## MVP

- Bright Iruka landing page
- Random pack pull flow
- Rarity and odds display
- Reveal animation
- Vault, sell, and ship actions
- Privy login with external EVM wallets
- English and Korean UI

## Next

- Production inventory records
- Real vault custody workflow
- Marketplace listings
- Redemption and shipping operations
- Pack policy pages
- GitBook docs at `https://docs.playiruka.io`

## Later

- Fan community boards
- Group and collection discussion pages
- User collection profiles
- Marketplace leaderboard
- More detailed vault and proof-of-custody records
- GIWA integration documentation

## Community Boards

Iruka plans to open community boards so idol fans and collectors can share pulls, discuss drops, and follow collections together.
